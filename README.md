# クラシック版 Outlook メール受信設定 確認・統一ガイド

同じメールアドレスを複数台の端末で共有（POP受信）している環境で、「一部の端末にメールが届かない」といった受信トラブルを防ぐための設定確認・統一ガイドです。単一ファイル（`index.html`）で動作するインタラクティブな手順書として構成しています。

## 公開ページ（GitHub Pages）

- **ガイドを開く:** `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`
  （※GitHub Pagesを有効化したあと、ご自身のURLに書き換えてください）

## 主な特徴

- **迷わない2カラム構成**: 左側の全体マップ（目次＋現在地ハイライト）と右側の手順ドキュメントを連動させ、怪しい端末の見分け方からSTEP 1〜4の設定統一、運用上の注意点まで順番に確認できます。
- **端末チェックリスト（ドロワー）**: 画面右上のボタンから必要なときだけ開閉できます。任意台数まで行を追加でき、統一基準日数（14日／30日）より短い削除日数が入力されたPOP端末には自動で警告バッジを表示します。
- **ライト／ダークモード切替**: 読みやすいライトモードをデフォルトとし、ワンクリックでダークモードへ切り替え可能です。
- **プライバシー・セキュリティ重視の設計**:
  - 外部ライブラリ・CDNを一切使用しない完全ゼロ依存（オフライン動作可）
  - 厳格な CSP（Content Security Policy）により外部通信を遮断
  - Cookie・`localStorage`・`sessionStorage` は一切不使用
  - ページを閉じる（`pagehide`）とチェックリストの入力値をメモリから自動消去
  - 印刷・PDF保存時は端末名・担当者名を含むドロワー領域を自動で非表示

## 使い方

### 1. ブラウザーでそのまま開く（おすすめ）
GitHub Pages の公開URLにアクセスするか、リポジトリから `index.html` をダウンロードしてダブルクリックで開きます。

### 2. ローカル環境で動かす場合
特別なビルドやサーバー構築は不要です。`index.html` 単体で動作します。
